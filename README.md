# ♻️ SmartWaste – AI Powered Waste Management

SmartWaste is a web-based waste management prototype that uses AI to help users identify different types of waste and understand how they should be managed.

## 🚀 Features

- 🤖 AI Waste Scanner
- ♻️ Waste classification into different categories
- 📊 Waste management dashboard
- 📍 Nearby waste collection centres with directions
- ❓ FAQ section
- 💬 User feedback section
- 🌱 Awareness and responsible waste-management information

## 🧠 AI Waste Categories

The AI scanner classifies waste into:

- Organic / Wet Waste
- Recyclable / Dry Waste
- E-Waste
- Special Care Waste
- Other

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- TensorFlow.js
- Google Teachable Machine

## 🎯 Project Goal

The goal of SmartWaste is to make waste segregation easier by combining AI-based waste identification with useful information about responsible waste management.

## 👩‍💻 Project

Developed as a software prototype for Smart India Hackathon (SIH).
